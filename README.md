# Student Management System

A simple desktop application built with Python to manage student records through a graphical user interface.

## Objective
This project is a GUI-based desktop application designed to handle basic student administration tasks. It includes a login interface and a main management dashboard where student records can be created, viewed, updated, and deleted.

## What Was Used
* Python 3
* Tkinter (Python standard GUI toolkit)
* Pillow / PIL (for rendering visual assets and background images)
* Database connectivity (MySQL / SQLite)

## Results and Features 
* Authentication: Secures access through a username and password login screen.
* Student Record Management: Allows users to add new students, update existing details, search records, and remove entries.
* Dashboard Interface: Displays structured student information alongside graphical elements and branded icons.

## How to Run
1. Ensure Python 3.x is installed on your system.
2. Install required Python packages:
   pip install pillow pymysql
3. Clone or download this repository.
4. Run the application: 
   python main.py
